# v1.0.1 更新说明

> 发布日期：2026-11-09
> 性质：缺陷修复，不新增功能。老用户免费更新，不计入大版本更新期。

## 修了什么

**桌面端音乐面板连不上引擎。**

在 DSH 桌面应用里，对话框上方的音乐条一直显示「连不上音乐引擎（试过 18990 / 17890）」，但在浏览器里打开同一个界面却是好的。

原因：桌面壳的页面用的是 `dsh-app://app/` 协议，不是 `http://127.0.0.1`。引擎只认回环 Origin（`127.0.0.1` / `localhost` / `::1`），桌面壳发来的请求全被判成 401；面板拿到 401 后统一报「连不上」，于是看起来像服务没启动。

修复：`engine/music_engine/server.py` 的 `_origin()` 现在额外接受 `dsh-app://app` 与 `Origin: null`（本地文件）。引擎仍然只绑 `127.0.0.1`，外网页面伪造不了这两个来源，接口没有对外放开。

## 顺带改的

- 面板的报错文案改成能指路：再遇到 401 会直接说「引擎拒绝了当前界面的来源，更新 dsh-music 到 1.0.1 或更高」，不再是笼统的「连不上」。
- 引擎版本号 `__version__` → 1.0.1。

## 怎么更新

1. 交付站登录后重新下载安装包（1.0.1），覆盖安装即可，工程和授权都保留。
2. 已经装好的：把交付站的新包解开，用 `install.ps1` 或 `一键安装.cmd` 重跑一遍；只想手动换的，替换插件目录里的 `engine/music_engine/server.py` 一处也能修好。
3. 更新后重启 DSH 桌面应用（引擎进程要跟着换新代码），音乐条就会连上。

## 验证过什么

- 用 `Origin: dsh-app://app` 请求 `/v1/panel/state`：预检 `OPTIONS` 200 且回 `access-control-allow-origin: dsh-app://app`；`POST` 返回 `ok: true`（15 个曲风、47 个工程）。
- 用 `Origin: http://127.0.0.1:50579` 请求：仍 200，浏览器端没被破坏。
- 用 `Origin: https://example.com` 请求：仍 401，没有把接口放开给外网。
