# DSH Music 1.0.3

1.0.3 只修问题，不加新功能。五处改动，两处会直接影响你听到的东西。

## 1. 鼓终于按曲风走了

之前所有曲风共用摇滚鼓谱，trap 只有 8 分音符踩镲、citypop 是摇滚的鼓组。现在每个曲风用自己的鼓谱和律动：

- trap 同一段 4 小节踩镲从 32 个变成 62 个（16 分 + 滚奏），该有的军鼓/开镲位置也对上了；
- lofi / hiphop / rnb / citypop / folk / guofeng / trap 有了真正的 swing（反拍落在 0.66–0.67，不再靠随机抖动假装）；
- 之前写好的 12 套鼓谱（`kit.py`）第一次真正进到编曲里。

**这会改变已有工程的听感**：重新 `music_compose` 出来的鼓和以前不一样，这是修好的结果。不想要新鼓就在编曲前把曲风改回 rock。

## 2. 母带不再把鼓压平

原来的链路是「混音先压到目标 -5 dB，母带再加回来」，每加 1 dB 都在削鼓点。现在：

- 混音只压到目标 -3 dB，母带补的增益封顶 6 dB；
- 同一段 citypop：动态范围（crest）从 7.31 dB 提到 8.03 dB，目标响度只降 0.38 dB；
- `overCompressed` 原来用固定阈值 7.0，压过头也判 false；现在按「进母带前后动态损失 > 3 dB」判，能真的报警。

**已知限制（诚实版）**：trap、house 这类目标很响（-8 / -9 LUFS）的曲风，当前用的还是软削波，不是真限幅器。为了不把鼓压平，母带最多补 6 dB，所以成品可能比目标低 1–4 LU。真限幅器在 1.1 的母带链重做里。

## 3. 面板和音效库接口不再对网页敞开

之前 `panel/`、`library/` 两类接口不校验 token，并且把 `Origin: null` 当本机——任何网页里的 sandboxed iframe 都能读你的工程列表、874 个音效和系统回环音频，还能替你编曲。现在：

- `Origin: null` 一律拒绝（同时按 `Sec-Fetch-Site: cross-site` 拦跨站请求）；
- 仍然放行 DSH 桌面壳（`dsh-app://`）、本机 DSH 网页（`http://127.0.0.1:端口` 或 `http://localhost:端口`）和带正确 token 的请求。

**唯一受影响的用法**：用浏览器直接打开本地 html 文件、或从 file:// 页面调引擎——这类请求会被 401。面板本身走 DSH 网页端，不受影响。

## 4. 版本号不再骗人

`GET /health` 和 `music_doctor` 以前永远报 0.16.0（硬编码）。现在读包内 `package.json`，装 1.0.3 就显示 1.0.3。

## 5. 三个「传了但没生效」的参数接上

- `music_render only`：只重渲指定轨，改一轨谱面不用整首重渲；
- `music_master fadeOut`：淡出秒数，之前实现了但工具层没暴露；
- `music_tune strength`：调教强度，之前工具 schema 缺字段，传了被丢掉。

另外 `music_render quality` 的说明改成实话：它现在还只写进报告，不改输出采样率（要改采样率用 `music_master` / `music_export` 的规格参数）。

## 6. 端口被占用时说人话

默认端口 17890 如果被别的插件占了，以前只会报「音乐引擎启动失败」加一屏日志。现在会直接说「端口 17890 已被别的程序占用」，并告诉你在 profile 里把 `enginePort` 改成 17891 再重连。`cordis.patch.yml` 里「自动换端口」的旧说明已删掉——那个功能从来没实现过。

---

## 怎么升级

覆盖安装，工程和母带不受影响：

1. 下载新的 `dsh-music-1.0.3.zip`，整个解压到新目录；
2. 双击 `一键安装.cmd`（会覆盖旧插件包，工程文件在 `~/Music/dsh-music` 不动）；
3. 重启 DSH，`music_doctor` 里 `engine` 应显示 `ok 1.0.3`。

个人版在更新期内免费；到期的用户按原来的补丁政策，1.0.2 修的问题都算补丁，可以单独索取 1.0.3 的引擎补丁包。

## 验证记录（本机，Windows 11 / Python 3.12.14）

- 鼓：同工程 4 小节 trap，新链路 verse 踩镲 62 个（旧 32 个）；
- 响度：citypop 8 小节，旧链路母带 -10.15 LUFS / crest 7.31 / overCompressed=false；新链路 -10.53 / 8.03 / true；
- 鉴权：`Origin: null` 401、`https://evil.example` 401、`Sec-Fetch-Site: cross-site` 401、本机网页 200、`dsh-app://` 200；
- 只渲鼓：`render(only='drums')` 只产出 `audio/render-v1/drums.wav`；
- 淡出：`fadeOut=1.0` 写出 `report/master-v1.json` 的 `fadeOut: 1.0`，不传为 0.0。
