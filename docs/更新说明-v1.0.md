# DSH Music 1.0 更新说明

1. **装得上：新增一键安装。** 包根多了 `一键安装.cmd` 和 `install.ps1`，双击即可自动找 DSH profile、安装 tgz、建 Python venv、装依赖、补 `dsh.profile.bundles`。想先看计划不落盘，用 `install.ps1 -CheckOnly`。
2. **装完能自查：新增 `scripts\doctor.ps1`。** 逐项检查 Node、ffmpeg、FluidSynth、SoundFont、Python venv、核心模块、肥鱼声音服务 9880、工程目录可写和磁盘空间；中文 ✅/❌ 加修复命令，`-Json` 可给售后贴机器可读结果。
3. **开箱能听：新增 3 个示例工程。** `examples\instrumental-30s`（纯器乐 30 秒）、`examples\beat-drums-bass-keys`（鼓/贝斯/键盘 beat）、`examples\mix-practice`（六轨混音练习），都带真实 MIDI，`music_project op=open` 打开后可直接 render。
4. **报错能查：新增 `docs\错误手册.md`。** 按安装、引擎、工程、渲染、混音、人声、分析、导出等分组，收录 50+ 条真实报错原文，每条给原因、处理和可复制命令。
5. **安装有据：新增 `docs\安装指南-v1.0.md`。** 用户视角一页装完，另附「装不上怎么办」三条兜底（找不到 profile / 系统依赖装不上 / venv 与 pip 失败）。
6. **许可明确：新增根目录 `LICENSE`（MIT）。** 版权行 `Copyright (c) 2026 DSH Music / 飞鱼p`；`package.json` 版本升到 1.0.0，`files` 白名单补上示例、安装脚本和许可证。
