# DSH Music 1.0 安装指南

> 目标：从解压到听见第一段声音，**一页装完**。装完不需要读别的文档。
> 适用：Windows 10 / 11（64 位），已安装 DeepSeek Harness（DSH）。

## 你会拿到什么

一个 zip，里面通常有：

- `dsh-music-1.0.3.tgz` —— 插件本体（工具 + 音乐引擎）
- `dsh-music-panel-0.5.1.tgz` —— 输入框上方那条「♪ 音乐」面板
- `一键安装.cmd` —— 双击这个
- `install.ps1` —— 安装脚本（cmd 会调用它）
- `README.md` / `docs\安装指南-v1.0.md` —— 说明

先**整个解压到一个普通目录**（例如 `D:\dsh-music-install`），不要在压缩包里直接双击。

## 装之前，确认三件事

1. **DSH 已经能启动**，并且 `dsh` 命令在 PATH 里（开始菜单能搜到 DSH 即可；不确定就先打开一次 DSH）。
2. **Node.js 20 或更高**。安装脚本会检查；没有会提示用 winget 装。
3. **磁盘至少留 2 GB**（Python 依赖 + 两个 SoundFont 约 200 MB，工程和渲染另算）。

ffmpeg / FluidSynth / SoundFont 不要求提前装：安装脚本会检查，缺了会问你要不要用 winget 装；SoundFont 缺了会告诉你放哪。

## 五步装完

### 第 1 步：双击 `一键安装.cmd`

会弹出一个 PowerShell 窗口。不要关，等它跑完。

脚本会依次做：

1. 找到 `%USERPROFILE%\.dsh\profiles` 下的 profile。只有一个就自动用；有多个会列出来让你输入编号。
2. 把两个 tgz 复制到 `C:\Users\Public\dsh-music-stage-<pid>\`（纯 ASCII 目录，避开中文路径传参乱码），再用 `dsh plugin --profile <你的 profile> add "file:<tgz 绝对路径>"` 依次装插件本体和面板，装完清掉暂存目录。
3. 确保 profile 的 `dsh.profile.bundles` 里有 `dsh-music` 和 `dsh-music-panel`（会保留原缩进、先备份再原子替换）。
4. 解压 tgz 到临时目录，运行 `scripts\bootstrap.ps1`：建 Python venv、装依赖、复制音乐 skill。
5. 检查 ffmpeg / FluidSynth；缺了给 winget 命令并问你是否现在装。
6. 跑 `scripts\doctor.ps1`，逐项打印 ✅ / ❌。

> 只想先看看会做什么、不装任何东西：在该目录打开 PowerShell，运行
> `powershell -ExecutionPolicy Bypass -File .\install.ps1 -CheckOnly`
> 它会列出 profile、检查工具、打印完整计划，然后退出，**不改任何文件**。

### 第 2 步：处理 doctor 的 ❌

安装最后会打印体检结果。常见的两项：

- **肥鱼声音服务（9880）❌**：只有做人声/和声/调教才需要。启动服务：
  `powershell -ExecutionPolicy Bypass -File ".\scripts\setup_voice_service.ps1"`
  不做人声可以先不管，其它功能照常。
- **工程目录可写 ❌**：换一个你有写权限的目录，或在 DSH 配置里改 `projectsRoot`。
- **SoundFont（FluidR3_GM）❌**：插件不带这个 141 MB 的鼓组音源。**1.0.2 起不再因此失败**——鼓会自动回退到包内的 GeneralUser，照样能渲染；想要更全的鼓组，把 `FluidR3_GM.sf2` 放到 `%USERPROFILE%\soundfonts\` 即可。

其余 ❌ 按 doctor 给的修复命令处理，处理完再跑一次：

```powershell
powershell -ExecutionPolicy Bypass -File ".\scripts\doctor.ps1"
```

### 第 3 步：重启 DSH

**完全退出 DSH 再打开**（不是关窗口，是退出进程）。插件和 profile 的 bundle 列表在启动时读取。

### 第 4 步：选「音乐模式」

在 DSH 的模式/预设里选 **音乐模式**（内部 id 是 `preset-music`）。选完后工具列表里会出现 `music_*`。

### 第 5 步：对 agent 说一句话

```text
跑 music_doctor
```

看到逐项检查结果，就装好了。想直接听声音：

```text
music_project op=open project="C:\Users\你\Music\dsh-music\triplet-demo"
music_render project="C:\Users\你\Music\dsh-music\triplet-demo"
```

没有工程？用 `examples\` 里的三个示例，见 `examples\README.md`。

## 装不上怎么办（三条兜底）

### 兜底 1：脚本说找不到 profile / 找不到 dsh

先确认 DSH 真的装过、并且 `dsh` 在 PATH：

```powershell
where.exe dsh
Get-ChildItem "$env:USERPROFILE\.dsh\profiles" -Directory
```

- `where.exe dsh` 没结果：重开一个 PowerShell 再试；还不行就重装 DSH。
- profiles 目录不存在：先启动一次 DSH，让它初始化 profile。
- 有多个 profile 但不知道选哪个：选你平时用的那个；`desktop` 通常是默认桌面 profile。

也可以显式指定：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Profile desktop
```

### 兜底 2：ffmpeg / FluidSynth 装不上，或 winget 用不了

脚本会给出官方 winget 命令。winget 不可用时，手动装：

- **ffmpeg**：下载 Windows 版，把 `ffmpeg.exe` 所在目录加入 PATH，重开 DSH。
- **FluidSynth**：下载 Windows 版，把 `fluidsynth.exe` 所在目录加入 PATH，重开 DSH。
- **SoundFont**：把 `FluidR3_GM.sf2` 放到 `%USERPROFILE%\soundfonts\FluidR3_GM.sf2`。

验证：

```powershell
where.exe ffmpeg
where.exe fluidsynth
Test-Path "$env:USERPROFILE\soundfonts\FluidR3_GM.sf2"
```

### 兜底 3：Python venv / pip 装到一半失败

先看报错是网络还是 Python 版本。重跑一次 bootstrap 通常能续上：

```powershell
powershell -ExecutionPolicy Bypass -File ".\scripts\bootstrap.ps1"
```

如果提示 venv 目录损坏（缺 `Scripts\python.exe`），删掉再建（先确认路径是
`%USERPROFILE%\.local\share\dsh-music\venv`，不要删错）：

```powershell
Remove-Item -Recurse -Force "$env:USERPROFILE\.local\share\dsh-music\venv"
powershell -ExecutionPolicy Bypass -File ".\scripts\bootstrap.ps1"
```

公司网络/代理导致 pip 失败时，先给 pip 配镜像再重跑，例如：

```powershell
& "$env:USERPROFILE\.local\share\dsh-music\venv\Scripts\python.exe" -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple numpy scipy soundfile librosa pedalboard pyloudnorm pretty_midi mido pypinyin
```

> 仍然装不上：把 `doctor.ps1 -Json` 的完整输出、`%USERPROFILE%\.dsh\music\engine.log` 最后 80 行、以及安装窗口里报错的那一段发售后。不要只发一句「装不上」。
